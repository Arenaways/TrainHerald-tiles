# Arenaways/TrainHerald-tiles

Railway tiles for [TrainHerald](https://github.com/Arenaways/TrainHerald): 10870 tiles of 0.25° × 0.25°, OpenStreetMap data of 2026-11-24.

Served at <https://arenaways.github.io/TrainHerald-tiles/>: `manifest.json` lists every tile with a hash; tiles are at `rail/<lat>_<lng>.tile`; `stations.json` lists every named station and halt with its `name:*` variants, UIC code, position and tile.
