# arenaways/trainherald-tiles

Railway tiles for [TrainHerald](https://github.com/Arenaways/TrainHerald): 10868 tiles of 0.25° × 0.25°, OpenStreetMap data of 2026-09-21.

Served at <https://arenaways.github.io/trainherald-tiles/>: `manifest.json` lists every tile with a hash; tiles are at `rail/<lat>_<lng>.tile`.

Map data © OpenStreetMap contributors, available under the Open Database License (see `LICENSE`).
